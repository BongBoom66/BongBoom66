# GridHedge_XAUUSD — MT5 Grid Hedge EA (Exness Cent)

Expert Advisor មួយសម្រាប់ MetaTrader 5 (MQL5) ត្រូវបានរចនាឡើងតាមតម្រូវការ៖

- ដាក់ Layer ចំនួន 10 (កំណត់បាន) ខាង **Buy** និង 10 ខាង **Sell** គំលាតគ្នា **$2** (កំណត់បាន) គិតចាប់ពីតម្លៃចាប់ផ្តើម (base price)
- ពេលតម្លៃប៉ះកម្រិតនីមួយៗ EA បើក **Market order** ភ្លាមៗ (មិនមែន pending order ទេ)
- Lot size ថេរដូចគ្នាគ្រប់ Layer
- **រៀងរាល់ Tick** EA គិត Floating profit សរុបនៃ Position ទាំងអស់ (គិតពីតម្លៃចូលពិតរបស់ Layer នីមួយៗ) ពេលដល់ `InpProfitTargetUSD` → **បិទ Position ទាំងអស់ ហើយសាកគំរូ Grid ថ្មី** ភ្លាមៗ តម្រឹមតម្លៃចាប់ផ្តើមថ្មីនៅត្រង់តម្លៃទីផ្សារបច្ចុប្បន្ន (នេះជាលក្ខខណ្ឌបិទចម្បង)
- ប្រសិនបើខាង Buy ឬខាង Sell ម្ខាងណាមួយចូលគ្រប់ទាំង 10 Layer មុននឹងទាន់ត្រឡប់ដល់ profit target → EA នឹងបិទ Position ទាំងអស់ និងសាកគំរូ Grid ថ្មីដដែល (នេះជាលក្ខខណ្ឌបិទបម្រុង/ករណីអាក្រក់បំផុត ដែលរាប់ជាការខាត — មើលផ្នែក "ហេតុអ្វីខាតទីផ្សារ" ខាងក្រោម)

## ឯកសារ

- `GridHedge_XAUUSD.mq5` — កូដ EA ពេញលេញ, compile ដោយ MetaEditor (F7) នៅក្នុង MT5

## របៀបប្រើ

1. ចម្លងឯកសារ `GridHedge_XAUUSD.mq5` ទៅក្នុងថត `MQL5/Experts/` នៃ MT5 terminal របស់អ្នក (File → Open Data Folder)
2. បើក MetaEditor ហើយ compile ឯកសារនេះ (F7)
3. បើក Chart នៃ Gold តាម symbol ពិតរបស់ broker Exness Cent របស់អ្នក (ជាធម្មតាមាន suffix ដូចជា `XAUUSDc` — ត្រូវប្រើ symbol ត្រឹមត្រូវនៃ Cent account, មិនមែន `XAUUSD` ធម្មតាទេ)
4. អូស EA ចូល Chart នោះ ហើយបើក "Algo Trading"

## Input Parameters

| Parameter | អត្ថន័យ | លំនាំដើម |
|---|---|---|
| `InpLotSize` | Lot size សម្រាប់ Layer នីមួយៗ (ថេរដូចគ្នាទាំងអស់) | 0.01 |
| `InpGapUSD` | គំលាតតម្លៃរវាង Layer ($) | 2.0 |
| `InpLayers` | ចំនួន Layer ក្នុងមួយខាង (Buy/Sell) | 10 |
| `InpSlippagePoints` | Slippage អតិបរមាសម្រាប់ market order | 30 |
| `InpProfitTargetUSD` | បិទ Grid ទាំងអស់ + សាកដើមវិញ ភ្លាមៗពេល floating profit សរុប (គិតពីតម្លៃចូលពិត) ដល់តម្លៃនេះ — លក្ខខណ្ឌបិទចម្បង។ កំណត់ជា 0 ដើម្បីបិទ Feature នេះ (ប្រើតែ full-side-fill ជាលក្ខខណ្ឌបិទ) | 1.0 |
| `InpMagicNumber` | Magic number កំណត់អត្តសញ្ញាណ trade របស់ EA នេះ | 20260802 |

## ហេតុអ្វីលក្ខខណ្ឌ "គ្រប់ 10 Layer បិទទាំងអស់" ខាតទីផ្សារ

Buy layer ដាក់ក្រោមតម្លៃ (ទិញពេលធ្លាក់) និង Sell layer ដាក់លើតម្លៃ (លក់ពេលឡើង) — នេះជា Grid ប្រភេទប្រឆាំង Trend។ ប្រសិនបើទីផ្សាររត់តែម្ខាងជាប់ៗគ្នារហូតដល់ Layer ទី 10 ចូលអស់ នោះ Layer ដំបូងៗនឹងខាតច្រើនបំផុត (ចម្ងាយឆ្ងាយបំផុតពីតម្លៃបច្ចុប្បន្ន) ចំណែកខាងម្ខាងទៀតគ្មាន Order ណាចូលសោះ — ដូច្នេះការបិទត្រង់ចំណុច Layer ទី 10 ចូលពេញ គឺជាចំណុចខាតធំបំផុតជានិច្ច មិនមែនចំណុចប្រសើរទេ។

នេះជាមូលហេតុដែល `InpProfitTargetUSD` ត្រូវបានធ្វើជាលក្ខខណ្ឌបិទ**ចម្បង** (default = 1.0) — EA នឹងព្យាយាមចាប់យក Profit តូចៗពេលទីផ្សារត្រឡប់មកវិញ ជាជាងរង់ចាំដល់ចុងបំផុត។ ការរង់ចាំគ្រប់ 10 Layer នៅតែជា Safety fallback ក្នុងករណីទីផ្សារមិនដែលត្រឡប់វិញសោះ ដែលករណីនោះនៅតែជាការខាតដដែល។

## ការប្រុងប្រយ័ត្ន (Risk warning)

EA នេះជាប្រភេទ **Grid/Hedge** ដែលបើកចំណាត់ការជាបន្តបន្ទាប់តាមទិសដៅដដែល (មិនមាន Stop Loss ក្នុងកម្រិត Layer នីមួយៗទេ)។ ប្រសិនបើទីផ្សាររត់ខ្លាំងទៅទិសណាមួយដោយបន្តដោយមិនត្រឡប់វិញសោះ (មិនដល់ profit target) លុយដែលត្រូវប្រើនឹងកើនឡើងតាម Layer ដែលចូល (គ្រប់ Layer ប្រើ Lot ថេរដូចគ្នា ដូច្នេះហានិភ័យកើនជាលីនេអ៊ែរតាមចំនួន Layer ដែលបានចូល មិនមែនជា Martingale ទេ) ហើយចុងក្រោយនឹងខាតត្រង់ចំណុច Layer ទី 10។ សូមសាកល្បងលើ **Demo account** ជាមុនសិន និងគណនាទំហំ Drawdown អតិបរមាដែលអាចកើតឡើង (10 Layer × Lot × គំលាតតម្លៃអតិបរមា) មុននឹងប្រើនៅលើ Real account។
