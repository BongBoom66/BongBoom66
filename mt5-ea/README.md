# GridHedge_XAUUSD — MT5 Grid Hedge EA (Exness Cent)

Expert Advisor មួយសម្រាប់ MetaTrader 5 (MQL5) ត្រូវបានរចនាឡើងតាមតម្រូវការ៖

- **តាម Trend**៖ ដាក់ Layer ចំនួន 10 (កំណត់បាន) ខាង **Buy នៅលើ** តម្លៃចាប់ផ្តើម (ទិញពេលឡើង) និង 10 ខាង **Sell នៅក្រោម** តម្លៃចាប់ផ្តើម (លក់ពេលចុះ) គំលាតគ្នា **$2** (កំណត់បាន) គិតចាប់ពីតម្លៃចាប់ផ្តើម (base price)
- ពេលតម្លៃប៉ះកម្រិតនីមួយៗ EA បើក **Market order** ភ្លាមៗ (មិនមែន pending order ទេ)
- Lot size ថេរដូចគ្នាគ្រប់ Layer
- **រៀងរាល់ Tick** EA គិត Floating profit សរុបនៃ Position ទាំងអស់ (គិតពីតម្លៃចូលពិតរបស់ Layer នីមួយៗ) ពេលដល់ `InpProfitTargetUSD` → **បិទ Position ទាំងអស់ ហើយសាកគំរូ Grid ថ្មី** ភ្លាមៗ តម្រឹមតម្លៃចាប់ផ្តើមថ្មីនៅត្រង់តម្លៃទីផ្សារបច្ចុប្បន្ន (នេះជាលក្ខខណ្ឌបិទចម្បង)
- ប្រសិនបើខាង Buy ឬខាង Sell ម្ខាងណាមួយចូលគ្រប់ទាំង 10 Layer មុននឹងទាន់ត្រឡប់ដល់ profit target → EA នឹងបិទ Position ទាំងអស់ និងសាកគំរូ Grid ថ្មីដដែល (នេះជាលក្ខខណ្ឌបិទបម្រុង/ករណីអាក្រក់បំផុត — មើលផ្នែក "ហេតុអ្វី Trend Grid ជាជម្រើសប្រសើរជាង" ខាងក្រោម)

## ហេតុអ្វី Trend Grid ជាជម្រើសប្រសើរជាង

កំណែដំបូង Buy layer ដាក់ក្រោមតម្លៃ (ទិញពេលធ្លាក់) និង Sell layer ដាក់លើតម្លៃ (លក់ពេលឡើង) — ជា Grid ប្រភេទ**ប្រឆាំង Trend**។ បញ្ហាគឺ បើទីផ្សាររត់តែម្ខាងជាប់ៗគ្នា ខាងម្ខាងទៀតគ្មាន Order ណាចូលសោះ ដូច្នេះការបិទត្រង់ Layer ទី 10 គឺជាចំណុចខាតធំបំផុតជានិច្ច (Layer ដំបូងឆ្ងាយពីតម្លៃបំផុត) ដោយគ្មាន Profit ខាងណាមកជួយ Balance។

កំណែថ្មីនេះប្តូរទិសដៅជា **តាម Trend**៖ Buy layer ដាក់**លើ**តម្លៃ (ទិញពេលឡើង តាមទិស Trend) និង Sell layer ដាក់**ក្រោម**តម្លៃ (លក់ពេលចុះ តាមទិស Trend)។ ចំណុចសំខាន់៖ ដោយសារ Layer ទាំងពីរខាងស្ថិតនៅផ្ទុយទិសគ្នាជុំវិញ Base ដូចគ្នា ពេលទីផ្សារឡើងចុះឡើងចុះ (Whipsaw) ទាំងពីរខាងអាចចូល Order បានទាំងអស់ ដែលធ្វើឲ្យ Position ខាង Buy និង Sell **កាត់កងគ្នា** (Net exposure តូចជាង Layer សរុប)។

ឧទាហរណ៍ (ស្របតាមករណីអ្នកលើកឡើង)៖ Sell ចូល 5 Layer (តម្លៃចុះ), ត្រឡប់ឡើងវិញចូល Buy 6 Layer, បន្ទាប់មកចុះមកវិញចូល Sell បន្ថែមរហូតដល់ Sell សរុប 10 Layer (គ្រប់លក្ខខណ្ឌបិទ) — ខណៈ Buy សរុបនៅ 6 Layer។ Net exposure ត្រឹមតែ 10 − 6 = **4 Layer** ប៉ុណ្ណោះ (មិនមែន 10 ដូចប្រឡែងអតីតកាលមិនត្រឡប់វិញសោះទេ) ព្រោះ Layer ភាគច្រើនត្រូវបានកាត់កងគ្នារួចហើយពេលទីផ្សារត្រឡប់ទៅមក។

`InpProfitTargetUSD` នៅតែជាលក្ខខណ្ឌបិទ**ចម្បង** (default = 1.0) — ព្យាយាមចាប់យក Profit ភ្លាមៗពេលទីផ្សារត្រឡប់មកវិញ ជាជាងរង់ចាំដល់ Layer ណាមួយពេញ 10។ ការចូលពេញ 10 Layer នៅតែជា Safety fallback ចុងក្រោយ ប៉ុន្តែឥឡូវហានិភ័យតូចជាងមុនច្រើន ដោយសារការកាត់កងគ្នារវាង Buy/Sell។ **ភ្លាមៗពេលបិទ** (មិនថាបិទដោយ Profit target ឬដោយ Full-side-fill) EA នឹង**បើក Grid ថ្មីភ្លាមៗ** តម្រឹមតម្លៃទីផ្សារបច្ចុប្បន្ន ដើម្បីបន្តយុទ្ធសាស្ត្រនេះជាបន្តបន្ទាប់។

## ការប្រុងប្រយ័ត្ន (Risk warning)

EA នេះជាប្រភេទ **Trend Grid/Hedge** ដែលបើកចំណាត់ការជាបន្តបន្ទាប់តាមទីផ្សារ (មិនមាន Stop Loss ក្នុងកម្រិត Layer នីមួយៗទេ)។ ការកាត់កងគ្នារវាង Buy/Sell កាត់បន្ថយហានិភ័យក្នុងករណីទីផ្សារ Whipsaw ប៉ុន្តែ**មិនលុបបំបាត់ហានិភ័យទាំងស្រុងទេ** — ប្រសិនបើទីផ្សាររត់តែម្ខាងខ្លាំងតែម្តង (Trend បន្តលំដាប់ គ្មានការត្រឡប់ក្រោយសោះ) នោះខាងម្ខាងនោះនឹងចូលគ្រប់ 10 Layer ដោយខាងម្ខាងទៀតគ្មាន Order ណាជួយកាត់កងទាល់តែសោះ ដែលនៅតែស្មើនឹងករណីអាក្រក់បំផុតដូចមុន។ គ្រប់ Layer ប្រើ Lot ថេរដូចគ្នា (មិនមែន Martingale ទេ) ដូច្នេះហានិភ័យកើនជាលីនេអ៊ែរតាមចំនួន Layer ដែលបានចូល។ សូមសាកល្បងលើ **Demo account** ជាមុនសិន និងគណនាទំហំ Drawdown អតិបរមាដែលអាចកើតឡើង (10 Layer × Lot × គំលាតតម្លៃអតិបរមា, ករណី Trend តែម្ខាងគ្មានត្រឡប់វិញ) មុននឹងប្រើនៅលើ Real account។
